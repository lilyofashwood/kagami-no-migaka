# 𝗄𝐚𝗀𝐚𝗆𝐢-𝗇𝐨-𝗆𝐢𝗀𝐚𝗄𝐚 · provenance

[Kagami-no-Migaka](https://github.com/lilyofashwood/kagami-no-migaka) is Lily of Ashwood’s layered-poem workshop, with the companion inscription **かがみのしきしのみがか**. Lily originated its specifications, logic and experiments; code and design were developed with AI assistance. Historical **Kasaneuta · 重ね歌** remains the method name.

The former title **かのとこよ · 歌ノ常世** lives beside **よことのか · 夜言ノ香** in the README’s poetry. Their kana form an exact reversal pair. **歌=か** is the chosen reading in this coined phrase; the kanji give each reading its own poetic face.

The workbench keeps `kasane-uta.grid.v1` and `kasane-uta.utf8-hex.v1` unchanged. Downloads remain `kasane-uta-grid.json`.

## Recovered grids

The Nekomata specimen preserves the selected recovered grid, including **R=歌**. Its second path is `AFKPU / BGLQV / CHMRW / DINSX / EJOTY`. This successful branch corrects a historical path that repeats M and omits O. Both exact readings are regression-tested.

The Kitsune specimen comes from the supplied **狐火重ね詩 — Kitsune Kasaneuta** React artifact, whose original SHA-256 is `8aef3136a8e967753e279d7a471467c647281e2f06d71e5da644013e2bf83354`. Its grid is preserved, and both traversals are checked against separately specified strings. The supplied English glosses accompany the readings as literary interpretation.

The structural demonstration is a new geometry fixture. Earlier 4×4 and 5-row × 4-column experiments are separate stages; this application uses the 5×5 document contract.

## From archive to workshop

Explicit coordinate paths, one-visible-grapheme cells, malformed-input checks, safe DOM rendering, a separate optional exact-byte envelope and the loopback provider adapter belong to this implementation. General grapheme mode extends the historical single-kanji construction profile. The generator follows the supplied intentions and welcomes any creature or theme.

The complete 78-entry [Font Garden](https://github.com/lilyofashwood/font-garden) catalog is vendored in `lettering.js`, with original-map and new-recipe attribution retained internally. It dresses authored interface text while preserving grid cells, input, literal readings, code and payloads.

The dedicated loopback server enables model controls. Static pages run local grid and byte operations. Origin checks protect the adapter, and each provider request requires an explicit action.

Full source packets and private conversations remain in the local archive. Public fixtures exercise grid geometry, exact bytes, request formats and error handling offline.
